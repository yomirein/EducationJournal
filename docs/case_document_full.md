Как устроен пакет
Пакет — это документ, а не выгрузка из базы данных. Так выглядят материалы, которые Федерация получает от педагогов. Перенос этого текста в вашу модель курса входит в задачу кейса: жюри смотрит, выдерживает ли архитектура настоящее содержание.
Иерархия
Курс — самостоятельная программа по одному инструменту для определённых классов. У курса есть паспорт: классы, объём, инструмент, цель.
Модуль — тематический блок внутри курса.
Шаг — минимальная единица, которую ученик проходит и сдаёт. Шаги в модуле идут в указанном порядке.
Паспорт шага — таблица под заголовком
Тип шага — определяет, как шаг выглядит у ученика и как проверяется.
Проверка — автоматическая (ответ, выбор вариантов, тесты) или ручная, то есть работа уходит куратору в очередь.
Что сдаёт ученик — число, выбор, код, ссылку, скриншот, текст.
Условные обозначения
✓ — верный вариант ответа. Ученик не должен видеть отметку до отправки ответа.
Блоки «Правильный ответ», «Критерии проверки», «Эталонное решение» и скрытые тесты — для куратора и системы проверки. Тесты с пометкой «пример в условии» ученик видит вместе с задачей.
Блочные программы Scratch и Minecraft записаны текстом: одна строка — один блок, отступ — вложенность, «конец» закрывает цикл. В Minecraft перед блоком в квадратных скобках указан раздел палитры MakeCode. Задачи с тестами решаются на Python 3.

Тип шага

Что сдаёт ученик
—
Scratch — это среда, в которой программы собирают из цветных блоков, как из конструктора. Писать команды словами не нужно: блоки перетаскивают мышкой и защёлкивают друг под другом.
Из чего состоит окно Scratch
Сцена — прямоугольник справа вверху. На ней происходит всё, что делает программа.
Спрайт — персонаж на сцене. В новом проекте это Кот. Спрайтов может быть несколько, и у каждого своя программа.
Палитра блоков — слева. Блоки разложены по цветам: синие отвечают за движение, фиолетовые за внешний вид, жёлтые за события, оранжевые за управление.
Область скриптов — середина экрана. Сюда перетаскивают блоки и собирают из них программу.
Координаты
Место на сцене задаётся двумя числами. x показывает, насколько спрайт левее или правее центра, y — насколько выше или ниже. Центр сцены — точка x: 0, y: 0. Левый край сцены — x: −240, правый — x: 240.
Как запустить программу
Почти каждая программа начинается с жёлтого блока «когда щёлкнут по зелёному флажку». Нажали флажок над сценой — программа пошла. Красный восьмиугольник рядом всё останавливает.
Блоки выполняются сверху вниз, по одному. Порядок блоков — это и есть алгоритм.

Модуль 1.2. Циклы
Шаг 1.2.1. Повторить и всегда
Тип шага
Теория
Проверка
Засчитывается при прочтении
Что сдаёт ученик
—
Представь, что Коту нужно сделать 10 шагов по одному. Можно поставить 10 одинаковых блоков «идти 1 шагов» друг под другом. Но программисты так не делают: они используют цикл.
Цикл — это блок, который повторяет вложенные в него блоки несколько раз. В Scratch есть два главных цикла:
«повторить 10 раз» — выполняет блоки внутри ровно столько раз, сколько написано в окошке;
«повторять всегда» — выполняет блоки внутри бесконечно, пока не нажмёшь красную кнопку «Стоп».
Пример
когда щёлкнут по зелёному флажку
повторить (4) раз
    идти (50) шагов
    ждать (0.5) секунд
конец
Кот четыре раза пройдёт по 50 шагов с паузой. Всего он пройдёт 200 шагов.
После блока «повторять всегда» нельзя поставить другой блок: цикл никогда не закончится, и до следующего блока дело не дойдёт.

Тип шага

Что сдаёт ученик
—
До сих пор программа делала одно и то же при каждом запуске. Чтобы она реагировала на происходящее, нужны события и условия.
События
Жёлтые блоки-события запускают программу: «когда щёлкнут по зелёному флажку», «когда клавиша пробел нажата», «когда спрайт нажат». У одного спрайта может быть несколько таких программ, и каждая ждёт своего события.
Условие
Оранжевый блок «если … то» выполняет блоки внутри только тогда, когда условие верно. Условия — это голубые шестиугольные блоки из раздела «Сенсоры», например «касается края?» или «касается Яблоко?».
когда щёлкнут по зелёному флажку
повторять всегда
    идти (5) шагов
    если <касается края?> то
        повернуть вправо на (180) градусов
    конец
конец
Кот идёт, а коснувшись края, разворачивается. Условие проверяется на каждом повторе цикла.

Модуль 2.1. Code Builder и агент
Шаг 2.1.1. Кто такой агент
Тип шага
Теория

Что сдаёт ученик
—
В Minecraft Education у каждого игрока есть помощник — агент. Это маленький робот, который выполняет команды из твоей программы: ходит, поворачивает, ставит и ломает блоки.
Как открыть редактор кода
Создай мир: «Играть» → «Создать» → «Новый». Для заданий подойдёт плоский мир в творческом режиме.
В мире нажми клавишу C — откроется Code Builder.
Выбери MakeCode и создай новый проект. Программу собирают из блоков, как в Scratch.
Где искать блоки
Раздел «Игрок» — события, например «при команде в чате».
Раздел «Агент» — всё, что делает агент: двигаться, поворачивать, ставить и ломать блоки.
Раздел «Циклы» — блок «повторить … раз».
Первая программа
Программа запускается командой в чате. Если набрать в чате «прыг», агент переместится к игроку и пройдёт вперёд три блока.
[Игрок] при команде в чате «прыг»
    [Агент] телепортировать агента к игроку
    [Агент] агент перемещается вперёд на 3
Чат открывается клавишей T. Набери «прыг» и нажми Enter.
Если агента не видно, сделай шаг назад. Он появляется рядом с игроком и смотрит туда же, куда игрок.

Шаг 3.3.1. Цикл for и range
Тип шага
Теория
Проверка
Засчитывается при прочтении

—
Цикл for повторяет блок команд для каждого значения из последовательности. Функция range создаёт последовательность чисел.
range(5) — числа 0, 1, 2, 3, 4;
range(1, 6) — числа 1, 2, 3, 4, 5;
range(0, 10, 2) — числа 0, 2, 4, 6, 8.
n = int(input())
total = 0
for i in range(1, n + 1):
    total += i
print(total)
Переменная total называется накопителем: перед циклом в ней 0, а на каждом шаге к ней прибавляется очередное число.
Проверяющая система ограничивает время. Простой цикл на Python успевает примерно 10⁷ повторений в секунду, поэтому перед отправкой всегда смотрите на ограничения.
